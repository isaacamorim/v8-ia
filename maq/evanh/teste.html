🔧 NIST STEP File Analyzer & Viewer

Guia Completo Passo a Passo para Visualizar Modelos 3D

1
Download da Versão Oficial

Baixe a versão pré-compilada (mais fácil):

📥 Download STEP-File-Analyzer.exe
💡 Dica: Vá para a seção "Releases" no GitHub oficial do NIST e baixe o arquivo ZIP mais recente.
2
Instalação e Primeira Execução

Passos para instalar:

  • Extraia o arquivo ZIP baixado
  • Execute o arquivo STEP-File-Analyzer.exe
  • Na primeira execução, carregue um arquivo STEP de exemplo
  • Isso instalará componentes adicionais necessários
⚠️ Importante: Execute o software oficial do NIST primeiro para instalar todas as dependências necessárias.
3
Carregando Seu Arquivo STEP

Como carregar e visualizar:

  • Clique em "Browse" para selecionar seu arquivo .step ou .stp
  • Selecione "Generate Spreadsheet" se quiser análise detalhada
  • Marque "Generate Visualization" para ver o modelo 3D
  • Clique em "Generate" para processar
✅ Resultado: Você verá uma planilha Excel com dados do modelo e uma visualização 3D interativa no navegador.
4
Navegando na Visualização 3D

Controles da visualização:

  • Mouse esquerdo + arrastar: Rotacionar modelo
  • Scroll do mouse: Zoom in/out
  • Botão direito + arrastar: Mover modelo
  • Duplo clique: Centralizar visualização
🎯 Dica: Use os controles da interface para mudar cores, transparência e outros aspectos visuais.

📋 Requisitos do Sistema

  • Sistema Operacional: Windows (versão pré-compilada)
  • Microsoft Excel: Para gerar planilhas (opcional - gera CSV sem Excel)
  • Navegador Web: Para visualização 3D
  • Arquivos Suportados: .step, .stp (ISO 10303 Part 21)
A
Funcionalidades Principais

O que o NIST SFA faz:

  • Análise de Estrutura: Gera planilha detalhada com todas as entidades do arquivo STEP
  • Visualização 3D: Converte geometria B-rep para X3D/WebGL
  • Validação: Verifica conformidade com padrões ISO 10303
  • Metadados: Extrai informações sobre material, propriedades, etc.
  • Relatórios: Gera relatórios de qualidade e conformidade
B
Interface Detalhada

Opções principais da interface:

  • File Input: Selecionar arquivo STEP
  • Spreadsheet Options: Configurar quais dados extrair
  • Visualization Options: Configurar renderização 3D
  • Quality Options: Configurar validação e verificações
  • Output Directory: Onde salvar os resultados
C
Tipos de Saída

Arquivos gerados:

  • .xlsx: Planilha Excel com análise completa
  • .x3d: Modelo 3D em formato X3D
  • .html: Visualizador web interativo
  • .csv: Dados em formato CSV (se Excel não disponível)
  • .log: Log de processamento e erros
⚠️ Aviso: Esta opção é para usuários avançados. Recomenda-se usar a versão pré-compilada oficial.
1
Baixar Código Fonte

Baixe os arquivos necessários:

  • 📥 Código Fonte (GitHub)
  • 📥 freewrap651.zip
  • 📥 teapot.zip
2
Configurar Ambiente

Preparar diretórios:

mkdir C:\STEP-Analyzer mkdir C:\Tcl\lib cd C:\STEP-Analyzer

Extrair arquivos:

  • Extraia todos os arquivos do diretório 'source' para C:\STEP-Analyzer
  • Extraia freewrap.exe para C:\STEP-Analyzer
  • Extraia teapot.zip para C:\Tcl\lib\teapot
3
Compilar Executável

Executar comando de compilação:

cd C:\STEP-Analyzer freewrap -f sfa-files.txt

Isso gerará o arquivo sfa.exe

Para versão linha de comando (opcional):

# Baixar freewrapTCLSH.zip e extrair freewrapTCLSH.exe # Editar sfa-files.txt: trocar 'sfa.tcl' por 'sfa-cl.tcl' freewrapTCLSH -f sfa-files.txt
!
Problemas Comuns e Soluções

❌ Erro: "Arquivo não encontrado"

  • Verifique se o arquivo STEP está no formato correto (.step ou .stp)
  • Teste com um arquivo STEP de exemplo primeiro
  • Verifique se o caminho do arquivo não tem caracteres especiais

❌ Erro: "Visualização não carrega"

  • Verifique se tem um navegador web instalado
  • Desative bloqueadores de pop-up
  • Teste com outro navegador

❌ Erro: "Excel não encontrado"

  • Instale Microsoft Excel ou
  • Use a opção para gerar apenas CSV
  • Verifique se Excel está registrado no sistema

❌ Erro: "Compilação falhou"

  • Use exatamente freewrap651 (versões mais recentes não funcionam)
  • Verifique se todos os arquivos estão nos diretórios corretos
  • Execute como administrador
