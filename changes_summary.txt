## Resumo das Alterações Realizadas

1.  **Animações On Scroll:**
    *   Identificadas as seções candidatas para animações on scroll: Banner Principal, Sobre Nós, Destaque de Produtos, Diferenciais e Clientes.
    *   Implementada a lógica para adicionar a classe `active` quando o elemento entra na viewport, utilizando a Intersection Observer API.
    *   Adicionados estilos CSS básicos para as animações (fade-in e slide-in-bottom).

2.  **Rodapé:**
    *   O fundo do rodapé foi alterado para a cor cinza `#343a40`.
    *   A cor do texto no rodapé foi ajustada para `#f8f9fa` (branco) para melhor contraste.

3.  **Menu Lateral:**
    *   O ícone do menu lateral agora está posicionado corretamente à frente do círculo de fundo.

4.  **Outras Melhorias:**
    *   Adicionada uma transição suave para a mudança de cor do ícone no menu lateral ao passar o mouse.
    *   Removido o `text-shadow` global para evitar conflitos com outros estilos.
